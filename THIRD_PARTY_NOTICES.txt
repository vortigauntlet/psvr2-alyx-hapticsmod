A NOTE ON A PREVIOUS VERSION OF THIS FILE
-----------------------------------------
Earlier releases carried an attribution to HLA-NoVR-DualSense (GPL-3.0) "for
the optional native state layer". That layer does not exist in this codebase
and, by the look of the history, was removed some time ago; the notice was left
behind. There is no AOB scanning, no signature matching, no process memory
access and no injection anywhere in the source - `--uninstall` and a grep of
app/src both bear that out.

The stale notice is called out rather than silently deleted, because an
incorrect GPL attribution invites people to conclude this project carries
copyleft obligations it does not have, and quietly removing such a line looks
worse than explaining it.
